# RogerAndrade7.github.io

## 🚀 Tecnologias Utilizadas

* **HTML5 & Tailwind CSS**: Para uma interface moderna e otimizada.
* **JavaScript (ES6+)**: Lógica de interatividade e controle de tema.
* **FontAwesome**: Iconografia técnica.
* **Formspree**: Integração de backend para recebimento de mensagens sem exposição de scripts de servidor.

## ✨ Funcionalidades Principais

* **Modo Dark/Light**: Alternância fluida de temas com persistência via `localStorage`.
* **Botão Flutuante (FAB)**: Acesso rápido à troca de tema em qualquer posição da página.
* **Design Responsivo**: Adaptado para dispositivos móveis, tablets e desktops.
* **Segurança no Design**: Implementação de práticas de proteção de dados no front-end e formulários higienizados.
* **Foco em Cybersecurity**: Seção dedicada a Soft e Hard Skills voltadas para análise de vulnerabilidades e Pentest.
